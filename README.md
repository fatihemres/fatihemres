# Hi, I'm Fatih Emre 👋

I work in **localization project management** and build software at the intersection of useful products, practical automation, and enjoyable experiments.

My GitHub tracks a journey from **C#/.NET and WPF** through **SwiftUI and AR** to **desktop products, APIs, and automation** with **TypeScript, Rust, Python, and .NET**. I like turning ideas into usable, verifiable applications—one milestone at a time.

## What I'm exploring

- Reliable **local-first desktop software** and safe data import/export
- **APIs and integrations** that can become building blocks for larger applications
- **AI-assisted workflows** with human review, measurable costs and clear safety boundaries
- Product planning, acceptance tests, release discipline and maintainable software architecture

## Other experiments

The rest of this profile includes learning projects in **SwiftUI, ARKit/RealityKit, WPF, .NET and web development**. Some are early experiments or historical snapshots, not maintained production libraries.

## A few principles

- An implemented feature is not automatically a tested feature.
- Local user data and reliable recovery matter.
- Clear documentation should distinguish current capabilities from ideas and plans.
- A small, useful application can be more valuable than an endless list of features.
